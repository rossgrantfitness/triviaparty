# Content

- `questions/` — verified question packs, one JSON file per category (e.g. `science_general.json`). Only verified questions go here.
- `schema/` — JSON Schema every pack must pass (added in Phase 3).
- `drafts/` — unverified question batches waiting for review (created when drafting starts).

Question format: see `docs/MANIFEST.md` section 8.
