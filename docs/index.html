Host a game

The game runs on a Windows PC hooked up to the TV. Everyone else just uses this page.

Download for Windows
  1. Unzip it anywhere (right-click → Extract All).
  2. Double-click TriviaParty.exe. If Windows says it protected your PC, click More info → Run anyway.
  3. If Windows asks about network access, click Allow so phones can connect.
  4. Everyone opens this page on their phone and types the code on the TV.
